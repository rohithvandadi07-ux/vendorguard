# VendorGuard 🛡️

![VendorGuard](https://img.shields.io/badge/Security-VendorGuard-blueviolet?style=for-the-badge)

VendorGuard is a modern, enterprise-grade Vendor Risk Scorecard Platform. It performs automated cybersecurity checks on vendors by analyzing their domain, DNS records, SSL/TLS certificates, security headers, open ports, and checks reputation against third-party intelligence feeds. The system then generates a comprehensive risk score and severity classification.

## Features ✨

- **Domain & DNS Analysis**: WHOIS data, domain age, registrar, and DNS records.
- **SSL/TLS Analysis**: Certificate validity, expiration checks, and issuer analysis.
- **Security Headers**: Validation of CSP, HSTS, X-Frame-Options, etc.
- **Port Scanning**: Lightweight scanning of common exposed ports.
- **Reputation Check**: Integrations with VirusTotal, AbuseIPDB, and Shodan (supports mock data).
- **Risk Scoring Engine**: Generates an overall risk score (0-100) and severity classification (Low, Medium, High, Critical).
- **Modern Dashboard UI**: Clean, dark-mode "cyber aesthetic" built with React and TailwindCSS.
- **History & Reports**: Keep track of previous vendor scans and generate reports.
- **Authentication**: JWT-based secure user authentication.

## Quick Start 🚀

To get the platform running locally with minimal setup:

1. **Clone the repository** (if pushed to git):
   ```bash
   git clone https://github.com/yourusername/vendorguard.git
   cd vendorguard
   ```

2. **Set up environment variables**:
   Copy the example environment file:
   ```bash
   cp .env.example .env
   ```

3. **Run with Docker Compose**:
   ```bash
   docker-compose up -d --build
   ```

4. **Access the application**:
   - Frontend UI: [http://localhost](http://localhost)
   - Backend API Docs: [http://localhost:8000/docs](http://localhost:8000/docs)

## API Documentation 📚

The API documentation is automatically generated by FastAPI and Swagger UI. Once the application is running, you can interact with the API endpoints at `http://localhost:8000/docs`.

### Core Endpoints
- `POST /api/auth/register` - Register a new user
- `POST /api/auth/login` - Authenticate and receive a JWT
- `POST /api/scans/run` - Submit a vendor domain/IP for a security scan
- `GET /api/history` - Retrieve previously scanned vendors

## Development 💻

### Backend (Local)
1. `cd backend`
2. Create virtual environment: `python -m venv venv`
3. Activate: `source venv/bin/activate`
4. Install dependencies: `pip install -r requirements.txt`
5. Run server: `uvicorn main:app --reload`

### Frontend (Local)
1. `cd frontend`
2. Install dependencies: `npm install`
3. Start dev server: `npm run dev`
